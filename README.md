# Freshnet

Freshnet is a small social prototype built as a static PWA with Supabase-ready authentication.

## Features
- landing page for the product
- authentication flow (sign in / sign up)
- social feed with posting support
- offline cache via a service worker
- Android packaging compatible with Capacitor

## Run locally
```bash
npm install
npm run dev
```

Then open `http://localhost:8080`.

## Important
The project uses a public Supabase `anon` key and should keep secrets out of the frontend. For production, replace the placeholder values in `connexion.html`, `fil.html`, and `js/config.js`.

## Project structure
- `index.html` — home/landing page
- `connexion.html` — sign in / sign up page
- `fil.html` — feed page
- `js/auth.js` — auth logic and demo mode
- `js/feed.js` — feed logic
- `service-worker.js` — offline cache
- `manifest.webmanifest` — PWA manifest
- `supabase/schema.sql` — database schema for Supabase

## Deployment
This repository is ready for static hosting on GitHub Pages or similar services.
